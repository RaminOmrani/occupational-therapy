# 🩺 سامانه مدیریت کلینیک کاردرمانی «ترنج»

نرم‌افزار یکپارچه‌ی کلینیک کاردرمانی شامل **سایت عمومی**، **اپلیکیشن بیماران (PWA)** و **پنل‌های مدیریت، درمانگر و منشی** — با تم اختصاصی کاردرمانی، رابط کاربری راست‌چین فارسی و تقویم شمسی.

## ✨ امکانات

| بخش | امکانات |
|---|---|
| **مدیریت** | داشبورد آماری، بیماران، لیدها (CRM)، تولدهای نزدیک، مالی و گزارش درآمد، پیامک تکی/گروهی با فیلتر، الگوهای پیامک، انتقادات و پیشنهادات، مقالات سایت، کاربران و درمانگران، گزارش فعالیت (Audit)، **تنظیمات کامل در دیتابیس** (بدون وابستگی به env) |
| **منشی** | برنامه‌ریزی روزانه‌ی درمانگر/بیمار/ساعت با گرید زمانی و بررسی تداخل، **قطعی‌کردن برنامه‌ی روز** با ارسال خودکار پیامک به بیمار و درمانگر، کپی برنامه از روزهای قبل، ثبت پرونده، صورت‌حساب و پرداخت، لیدها |
| **درمانگر** | شرح‌حال اولیه، **۳ فرم ارزیابی** (پروفایل جسمی، مهارت‌های ادراکی-حرکتی، مهارت‌های شناختی) با امتیازدهی و نمودار روند، گزارش پیشرفت هر جلسه (SOAP)، عملکرد روزانه، اهداف درمانی با درصد پیشرفت، برنامه تمرین خانگی، جستجو با فیلتر تاریخ/بیمار/درمانگر |
| **بیمار** | ورود با کد پیامکی، برنامه جلسات و یادآوری ۲ ساعت قبل، مشاهده فرم‌ها و ارزیابی‌ها، **پروفایل مالی** (بدهکاری/بستانکاری، صورت‌حساب، کیف پول، تخفیف، مهلت پرداخت، وضعیت تسویه)، تمرین خانگی با ثبت انجام روزانه، انتقاد و پیشنهاد و دریافت پاسخ |
| **سایت عمومی** | صفحه نخست با معرفی خدمات و درمانگران، مقالات با دسته‌بندی و جستجو، فرم تماس/رزرو که مستقیم **لید CRM** می‌سازد |

**شماره پرونده یکتا** (`OT-00001`)، شماره لید (`L-00001`) و شماره صورت‌حساب (`INV-00001`) به‌صورت خودکار و ترتیبی صادر می‌شوند.

## 🧱 معماری

```
apps/api      Express 5 + TypeScript + Prisma 6 (SQLite پیش‌فرض) + JWT + node-cron
apps/web      Next.js 15 (App Router) + Tailwind + React Query + Recharts — RTL / Vazirmatn
packages/shared  ثابت‌ها، قالب ارزیابی‌ها، الگوهای پیامک، توابع تاریخ شمسی (مشترک بین API و وب)
```

- مرورگر فقط با دامنه‌ی وب صحبت می‌کند؛ Next.js درخواست‌های `/api/*` را به API پراکسی می‌کند (کوکی ورود هم‌دامنه و HttpOnly).
- **تنظیمات** (نام کلینیک، ساعات کاری، پیامک، قیمت جلسه، یادآوری‌ها و...) در جدول `Setting` ذخیره و از پنل مدیریت ویرایش می‌شوند. کلید امضای توکن هم خودکار ساخته و در دیتابیس نگه‌داری می‌شود.
- **پیامک**: آداپتور ملی‌پیامک با دو حالت `melipayamak-rest` (نام کاربری/رمز) و `melipayamak-console` (کلید API) + حالت `mock` برای توسعه. الگوهای سیستمی قابل ویرایش‌اند و برای ارسال خدماتی می‌توان کد الگو (bodyId) ثبت کرد. جزئیات در [docs/sms.md](docs/sms.md).
- **زمان‌بند**: هر دقیقه یادآوری جلسات (N ساعت قبل، قابل تنظیم)، ۸ صبح تبریک تولد (اختیاری)، ۸:۳۰ و ۱۸ اعلان لیدهای نیازمند پیگیری و برنامه‌ی فردا که هنوز قطعی نشده.

## 🚀 اجرا

پیش‌نیاز: Node.js 20+ و pnpm (`npm i -g pnpm`)

```bash
pnpm setup      # نصب وابستگی‌ها + ساخت دیتابیس + داده‌های نمونه
pnpm dev        # API روی :4000 و وب روی :3000
```

سپس به http://localhost:3000 بروید.

| نقش | شماره موبایل | رمز |
|---|---|---|
| مدیر | 09120000001 | admin1234 |
| منشی | 09120000002 | admin1234 |
| درمانگر | 09120000003 و 09120000004 | admin1234 |
| بیمار نمونه | 09120000010 | OT-00001 (یا کد پیامکی) |

> در حالت پیش‌فرض (mock) کد ورود پیامکی در لاگ ترمینال API و در «پیامک ← گزارش ارسال» دیده می‌شود.

### دستورات مفید

```bash
pnpm db:push     # اعمال تغییرات schema روی دیتابیس
pnpm db:seed     # داده‌های نمونه
pnpm db:studio   # مرورگر دیتابیس Prisma
pnpm typecheck   # بررسی تایپ همه پکیج‌ها
pnpm build && pnpm start   # اجرای production
```

### استقرار (Production)

1. `pnpm install && pnpm build`
2. متغیرهای اختیاری: `PORT` (API)، `API_URL` (آدرس API برای وب، پیش‌فرض `http://localhost:4000`)، `WEB_ORIGIN` (برای CORS)، `TZ` (پیش‌فرض `Asia/Tehran`).
3. `pnpm start` (یا هر دو اپ را با pm2 اجرا کنید). فایل دیتابیس در `apps/api/data/clinic.db` و آپلودها در `apps/api/uploads` هستند؛ از این دو پوشه بکاپ بگیرید.
4. برای PostgreSQL کافی است `provider` و `url` در `apps/api/prisma/schema.prisma` را تغییر داده و `pnpm db:push` بزنید.
