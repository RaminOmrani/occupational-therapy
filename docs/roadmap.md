# فازهای بعدی — وضعیت

## ✅ پیاده‌شده در فاز دوم

| ایده | وضعیت | نکته |
|---|---|---|
| نوبت‌دهی آنلاین از سایت | ✅ آماده | صفحه `/book`؛ درمانگر و زمان خالی بر اساس روزهای کاری و نوبت‌های موجود. درخواست‌ها در «نوبت‌های آنلاین» پنل تأیید/رد می‌شوند؛ با تأیید، پرونده (اگر نبود) و نوبت ساخته و پیامک می‌رود. |
| پیام‌رسانی درمانگر ↔ بیمار | ✅ آماده | «پیام‌ها» در پنل کارکنان و «پیام به درمانگر» در پنل بیمار؛ اعلان درون‌برنامه و نشانگر نخوانده. |
| رضایت‌سنجی خودکار | ✅ آماده | پس از هر ۵ جلسه انجام‌شده (قابل تنظیم) لینک نظرسنجی پیامک می‌شود؛ پاسخ به «انتقادات و پیشنهادات» می‌رود و امتیاز پایین به مدیر اعلان می‌دهد. نیاز به تنظیم «آدرس سایت» دارد. |
| گزارش‌های مدیریتی | ✅ آماده | «گزارش‌های مدیریتی»: نرخ تبدیل لید، نرخ غیبت، عملکرد و درآمد هر درمانگر، روند ۶ ماهه، بیماران در خطر ریزش با دکمه پیامک پیگیری. |
| رضایت‌نامه با امضای دیجیتال | ✅ آماده | متن در تنظیمات؛ بیمار در پنل خود با انگشت/ماوس امضا می‌کند؛ نسخه قابل چاپ. با تغییر متن، امضای مجدد لازم است. |
| درگاه پرداخت آنلاین | ✅ کد آماده — نیاز به مرچنت | زرین‌پال (API v4). تا دریافت مرچنت، «حالت آزمایشی» فعال است. **پیش‌نیاز:** ثبت‌نام در zarinpal.com، ساخت درگاه و وارد کردن مرچنت آی‌دی در تنظیمات + آدرس واقعی سایت (https). |
| بکاپ خودکار | ✅ محلی آماده | هر شب ۳ بامداد + دکمه «بکاپ الان» و دانلود در تنظیمات ← امنیت. **برای بکاپ ابری** به فضای ذخیره‌سازی (مثلاً آروان/لیارا با کلید S3) نیاز است؛ با دریافت کلیدها اضافه می‌شود. |

## ⏳ نیازمند پیش‌نیاز از سمت شما

| ایده | چه چیزی لازم است |
|---|---|
| اپ موبایل نیتیو (اندروید/iOS) | حساب توسعه‌دهنده گوگل‌پلی (۲۵ دلار یک‌بار) و اپل (۹۹ دلار سالانه) یا انتشار در بازار/مایکت؛ فعلاً PWA همان تجربه را روی موبایل می‌دهد (Add to Home Screen). API آماده اتصال اپ نیتیو است. |
| چند شعبه | تصمیم درباره مدل (شعبه‌های مستقل یا مشترک) و اینکه کدام گزارش‌ها تجمیعی باشند؛ سپس افزودن `branchId` به موجودیت‌ها. |
| یکپارچگی با بیمه / فاکتور رسمی | قرارداد با بیمه‌گر و مشخصات وب‌سرویس آن‌ها؛ برای فاکتور رسمی، مشخصات سامانه مودیان (شناسه یکتای حافظه مالیاتی و کلید امضا). |
| بکاپ ابری | کلید دسترسی فضای ابری S3-سازگار (آروان کلود، لیارا، ...) |
| پیامک واقعی | نام کاربری/رمز یا کلید API ملی‌پیامک + شماره خط اختصاصی؛ برای الگوهای خدماتی، کد هر الگو. |
